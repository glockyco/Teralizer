## Artifacts Evaluated – Reusable

> *"The artifacts associated with the paper are of a quality that significantly exceeds minimal functionality. That is, they have all the qualities of the Artifacts Evaluated – Functional level, but, in addition, they are very carefully documented and well-structured to the extent that reuse and repurposing is facilitated."*

We believe our artifact exceeds the Functional requirements and meets the Reusable criteria for the following reasons:

### Documentation Quality

| Aspect | Implementation |
|--------|----------------|
| Structured README | Clear sections for setup, verification workflows, and reproduction |
| Verification checkpoints | INSTALL.md provides numbered steps with expected outputs |
| Paper linkage | Explicit mapping from notebooks to paper figures/tables |

### Structure for Reuse

| Aspect | Implementation |
|--------|----------------|
| Modular design | Data collection (Teralizer) and analysis (notebooks) are independent |
| Configuration files | `project-configs/` contains templates for new projects |
| Parameterized scripts | Pipeline scripts accept dataset, count, and phase options |
| Output variants | Analysis supports `original`, `verify`, and `replicate` variants |
| Separate archives | Users download only what they need (results, core, projects, data) |

### Community Standards

| Standard | Implementation |
|----------|----------------|
| Docker containerization | All components run in isolated containers |
| Version pinning | Python via `uv.lock`, PostgreSQL 17.1, JDK 8 |
| Open source license | CC BY 4.0 for artifact, analyzed projects retain original licenses |
| Standard tools | Docker, Jupyter, PostgreSQL, Git |
| Reproducible builds | `Dockerfile.analysis` builds identical environment |

### Extension Support

| Capability | How |
|------------|-----|
| Add new projects | Add Maven/Gradle project to `projects/`, create config based on examples in `project-configs/` |
| Modify analysis | Edit notebooks, re-run with `./scripts/run-notebooks.sh` |
| Query raw data | Connect to PostgreSQL via Adminer or `psql` |
| Export results | Notebooks export LaTeX tables, CSV data, PDF figures |

## Summary

This artifact provides everything needed to:

1. **Verify** our results by re-running the analysis on the provided data
2. **Reproduce** the data collection by running the pipeline on the included projects
3. **Reuse** Teralizer on new Java projects by following the configuration examples
4. **Extend** the analysis by modifying the Jupyter notebooks

The artifact follows community standards for research software, uses containerization for reproducibility, and includes comprehensive documentation for all usage scenarios.
