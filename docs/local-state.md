# Local state: generated, gitignored, temporary

The single authority for local state: which code owns it and what is safe to delete. Other
docs link here instead of restating rows. Behavioral boundaries agents must obey stay in the
nested AGENTS.md beside the code they guard.

Rules that keep this doc from going stale:

- Rows describe patterns and owners, never the instances that exist today. What exists right
  now is `ls`, not documentation.
- No volatile numbers. Sizes and counts belong in dated audit docs under `docs/plans/`.
- Adding or removing a run driver or generator changes its row in the same commit.

## Run outputs under `data/` (gitignored)

Every run root carries an attempt ledger (`status.tsv`), per-project logs (`run-logs/`), and
resume markers (`done/`).

| Pattern | Owner | Retention rule |
|---|---|---|
| Reporeapers-lane run roots (`REPOREAPERS_DATA_DIR`, default `data/reporeapers-rerun`) | `scripts/run-reporeapers-rerun.sh` (also sentinel/hotspot/fusion lanes via `REPOREAPERS_CONFIG_DIR`) | A measurement run root stays with its snapshot DB. A scratch lane root (`*-verify`) is deleted with its scratch DB. |
| `data/verification/` (`VERIFICATION_DATA_DIR`) | `scripts/run-verification-corpus.sh` | Regenerated by every gate run. Delete freely. |
| `data/jarvis-*/` (`JARVIS_DATA_DIR`) | `scripts/run-jarvis-scoreboard.sh`, `scripts/run-jarvis-census.sh` | Fixtures and `source-cache/` are regenerable via `--prepare-fixtures`. `PROVENANCE.md` stays with the measurement outputs it describes. |
| Loose `data/github_com_*/` dirs | Historical pre-profile pipeline runs (the `postgres_test` era) | Kept deliberately as provenance for old snapshots. Revisit after the paper ships. |

## Other local state

| Pattern | Owner | Retention rule |
|---|---|---|
| `database/teralizer/` | Root `docker-compose.yml` Postgres (its PGDATA) | Live database storage. Never edit, never commit. |
| `database/db.sqlite` | Pre-Postgres pipeline era | Kept deliberately. Revisit after the paper ships. |
| `data-dev.zip` (root) | Old data snapshot | Kept deliberately. Revisit after the paper ships. |
| `logs/` | Pipeline loggers | Delete freely. |
| `project-configs/timeout-retry*.conf` | Timeout retry lane, regenerated from each run's timeout list | See `project-configs/AGENTS.md`. |
| Fixture residue under `verification/fixtures/` (`target/`, generated tests, `pom.teralizer*.xml`, `.jqwik-database`) | Pipeline runs against the fixtures | Swept by the verification driver at the next run. Delete freely. |
| Root transient junk (`hs_err_pid*.log`, `.jqwik-database`) | JVM crashes, jqwik | Delete freely. |
| Scratch databases (`postgres_verification`, `postgres_<purpose>_verify`, `teralizer_codegen`, per-run snapshot DBs) | Runner scripts via `scripts/lib/db-lifecycle.sh` | Created and dropped by their runners. Snapshot DBs of measurement runs join `src/main/resources/db/protected-databases.txt` and are never scratch targets. |
